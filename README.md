# Pnina Sasson — Portfolio

Personal portfolio site for Pnina Sasson, a Sociology student at Tulane University (B.A. expected May 2027) working across communications, consulting, and advocacy.

## What's here

- `index.html` — main page: about, selected work (AIPAC, TAMID consulting and recruitment, campus event leadership), experience, leadership, and contact.
- `media.html` — press and media features.
- `styles.css` — shared styles for both pages.
- `headshot.jpg`, `Pnina-Sasson-Resume.pdf` — photo and résumé linked from the site.

## Running it

It's a static site with no build step. Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).
